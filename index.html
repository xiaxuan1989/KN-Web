吸积盘与喷流

默认保留原启动参数；点击示例启用盘与喷流。盘需内半径小于外半径，并有厚度或漏斗斜率；喷流需吸积率 ≥ 0.01 且亮度大于 0。盘面沿自旋赤道，绕转相机可比较倾角。盘和喷流随时间倍率演化，设为 0 暂停；各频移指数可设为 0 做对照。

致密星表面

勾选后将半径设为 2 Rs 可观察表面；0 表示无表面。有视界时半径须大于外视界，裸奇点允许任意非零半径。当前场景只追踪正 r 区域，负半径表面需后续最大延拓。原模型以 6000 K 叠加噪声温度，自转随时间倍率演化；表面遮挡其后的天空、盘与喷流。原诊断 5 显示表面棋盘格。

四维观者控制

G 进入／退出四维模式。WASD / RF 施加推力，斜向保持相同推力大小；滚轮每档调整 1.2 倍。荷质参数作用于观者，区别于黑洞 Q*；默认 0。正／负快度沿选定方向加速／反向加速，静止时速度方向回退到视线方向。退出后恢复原普通相机位置并保持自由模式。

后处理

沿用无抖动历史混合；权重由帧间隔、质量和时间倍率决定，运动超过原阈值时只用当前帧。参数变化会渐变，时间倍率用于历史混合与四维轨迹推进。关闭后处理可对照原图，原诊断同样经过后处理，可关闭后处理查看诊断原色。

等待 GPU 回读

原诊断 1 显示当前已启用追踪分支的终止颜色；2 的红通道检查类光条件、绿蓝通道表示局部方向；3 使用 Count/MaxStep，超预算可超过红端；4 只给逃逸到天空的光线上色；6 在画面下半屏乘面积放大率。quality 可直接输入 10 或更高，FOV 支持 0° 与 180° 之间的值。

默认参数：质量 1490 万 M☉、自旋 0.998、电荷 0、水平 FOV 80°。启动与重置时，相机会逐渐靠近默认轨道。

点击画布后，T 切换自由视角。左键 / WASD 绕黑洞转，右键独立摆头，松手后惯性滑停；中键平滑回正，滚轮拉近 / 拉远黑洞，FOV 不变。

触屏：单指拖动对应左键，双指同向拖动对应右键，双指捏合对应滚轮。轨道模式下，张开拉近、合拢拉远；可同时缩放和转动视角。

空间网格沿光线叠加在固定 r 曲面上，随局部拖曳旋转并遮挡背景。模式 1 显示局部频移颜色，模式 2 用青／绿／红区分远处、外视界附近与内视界附近的曲面；内层是否可见由原视界规则决定。时间倍率可暂停或反向网格运动。

沿 NPGS 类光测地线追踪至 Universe 0 星空。切换「原背景」比较透镜畸变，切换「方向网格」观察临界曲线附近的多重成像。支持静态、落体、速度及四维轨迹观者，吸积盘与喷流可在面板独立开启。背景颜色频移采用 NPGS 映射；关闭可对照贴图原色，背景亮度倍率仅在开启时生效。

进入视界、预算耗尽或回转过多停止背景采样，保留已累计的盘、喷流与网格辐射（星空本身也有暗区）；观者无法保持类时速度时按原版输出黑色；紫色表示数值异常。超极限参数可追踪裸奇点的正 r 区域。

落体模式改变当地观测标架，不自动移动相机。速度模式默认使用相机移动产生的平滑坐标速度；勾选「指定观者速度」可做固定位置对照，单位为 c。坐标速度是否可用由当地时空度规判断。四维模式将启用时的位置和速度作为初值，随后沿轨迹移动；鼠标调整头部朝向；此时 T 暂停使用，WASD / RF 改为推力控制。时间倍率控制推进，设为 0 可暂停，重置相机重新出发。

默认随窗口调整输出尺寸和画面比例，预计算宽高各为输出的一半。不额外乘 Retina 像素倍率。取消「跟随窗口尺寸」可设置固定宽高。关闭预计算可对照全分辨率追踪；追踪预算随自旋、电荷和画质参数 quality 调整。距离用 Rs 归一化，固定相机 Rs 坐标时，单独改变太阳质量不会改变透镜形状。
